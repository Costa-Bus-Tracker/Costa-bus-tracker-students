1. ACTUALIZACION DE ARQUITECTURA TECNICA E INFRAESTRUCTURA AWS
- Migracion del modelo meramente simulado hacia una arquitectura hibrida validada en campo con nodos fisicos ESP32 + receptor satelital GPS u-blox (NEO-6M/M8N) y simulador en Python (simulator.py).
- Incorporacion de metricas empiricas reales obtenidas en AWS (region us-east-2, Ohio): 112 invocaciones en 15 minutos, duracion neta promedio de 545.56 ms, duracion facturada conservadora de 1,039 ms y consumo de memoria de 95 MB sobre 128 MB asignados.
- Dimensionamiento financiero de nube bajo esquema serverless (AWS API Gateway HTTP API + Lambda en Python + DynamoDB Bus-TrackerDB), demostrando un costo operativo de $1.56 a $4.95 USD/mes para toda la flota (intervalo recomendado de 30-60 s), entre 4 y 8 veces mas economico que una instancia EC2 t3.micro.
- Configuracion de almacenamiento gratuito a largo plazo (< 0.15 GB/mes dentro de los 25 GB permanentes de DynamoDB) con politica Time-To-Live (TTL) a 90 dias y expiracion de CloudWatch Logs a 30 dias.
